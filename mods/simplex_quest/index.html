Simplex Quest

A shared quest book, built once so every mod can use it. Register quests from your own mod and they show up in one common Quest Book GUI — no need to build your own screen from scratch.

↓ Download latest Report an issue
Early development. Quests display, but rewards aren't granted automatically yet, and there's no completion tracking. See the roadmap below.

What it does

01 · REGISTER

One API, any mod

Call SimplexQuestAPI.registerQuest(...) from your own mod's init — no need to touch Simplex Quest's code at all.

02 · DISPLAY

Shared Quest Book GUI

A right-clickable Quest Book item opens a chest-style screen showing every quest registered by every mod that depends on it.

03 · RECIPE-READY

Craftable, your way

No default recipe — any dependent mod can add its own crafting recipe for the shared Quest Book item.

Add it to your mod

// build.gradle
modImplementation files("libs/simplex_quest-0.1.0.jar")

// YourMod.java
SimplexQuestAPI.registerQuest(new Quest(
  "gather_wood", "Gather Wood",
  "Bring 20 Oak Logs to the Woodcutter.",
  "Reward: 5 Beast Coin"
));
